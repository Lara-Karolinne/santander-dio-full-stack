# Santander DIO Fullstack

Repositório dedicado aos meus estudos e à minha evolução em **desenvolvimento Full Stack**, reunindo os conhecimentos adquiridos nas trilhas de **Back-end Java** e **Front-end** da DIO em parceria com o Santander.

## ☕ Back-end com Java

Na trilha de Back-end, estou desenvolvendo conhecimentos desde os fundamentos da linguagem Java até a construção de aplicações e APIs utilizando o ecossistema Spring.

### Conteúdos estudados

- Princípios de desenvolvimento de software colaborativo;
- Fundamentos e sintaxe da linguagem Java;
- Lógica de programação aplicada com Java;
- Programação Orientada a Objetos (POO);
- Classes, objetos, métodos, encapsulamento, herança e polimorfismo;
- Estruturas de dados e conceitos fundamentais da linguagem;
- Testes em projetos Java;
- Gerenciamento de dependências;
- Banco de dados SQL e NoSQL;
- Desenvolvimento de aplicações com Spring Framework e Spring Boot;
- Criação e desenvolvimento de APIs REST;
- Boas práticas no desenvolvimento Back-end;
- Desenvolvimento colaborativo com Git e GitHub;
- Conceitos de metodologias ágeis e Soft Skills.

## 💻 Front-end

Na trilha de Front-end, estou aprendendo os principais fundamentos para criação de interfaces web, trabalhando desde a estrutura das páginas até estilos, responsividade e interatividade.

### Conteúdos estudados

- Estruturação de páginas web com HTML;
- Estilização de interfaces com CSS;
- Criação de layouts utilizando Flexbox e CSS Grid;
- Desenvolvimento de páginas responsivas;
- Fundamentos e lógica de programação com JavaScript;
- Interatividade e comportamento das páginas com JavaScript;
- Manipulação de elementos da página;
- Consumo de APIs;
- Requisições assíncronas;
- Desenvolvimento de páginas web dinâmicas;
- Construção de projetos práticos para aplicação dos conhecimentos adquiridos.

## 🎯 Aprendizado na prática

Além dos conteúdos teóricos, o aprendizado é complementado por atividades práticas que ajudam a consolidar os conhecimentos adquiridos ao longo das trilhas:

- **Cursos:** estudo dos conceitos e fundamentos das tecnologias utilizadas no desenvolvimento Full Stack;
- **Desafios de código:** resolução de exercícios para desenvolver lógica de programação e aplicar os conteúdos estudados;
- **Desafios de projeto:** desenvolvimento de projetos completos para colocar em prática diferentes conhecimentos;
- **Mentorias:** aprofundamento dos conteúdos, discussão de aplicações práticas e contato com experiências do mercado de tecnologia.

## 🚀 Objetivo

Este repositório tem como objetivo registrar minha evolução no desenvolvimento **Full Stack**, reunindo estudos e práticas em **Java, Spring, bancos de dados, HTML, CSS e JavaScript**, além da aplicação desses conhecimentos na construção de projetos e soluções completas.
